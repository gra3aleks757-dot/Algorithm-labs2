# Лабораторная работа: Линейные структуры данных (Bus Route)

## Описание проекта
Реализация системы маршрута автобуса, включающая список остановок. Каждая остановка содержит:
- название
- координаты (x, y)
- время до следующей остановки

---

# Laba main.py:

Содержит 5 функций:
- **stop** - добавление остановки в маршрут
- **total_time** - расчет общего времени маршрута
- **where_bus** - определение, где будет автобус через N остановок
- **reverse_route** - построение обратного маршрута
- **print_route** - вывод маршрута в консоль

## Формат данных:
Каждая остановка представлена списком:
- название
- координаты(x,y)
- время до следующей остановки

---

# Laba variant1.py:

Содержит функции для кольцевого маршрута:

- **stop** - добавление остановки в маршрут
- **totaltime_circle** - расчет времени полного круга
- **where_bus_circle** - определение позиции через N остановок (с учетом кольца)
  - Использует остаток от деления: n % len(route)
- **find_time** - поиск остановок, до которых автобус доедет за заданное время
  - Выводит остановки и время прибытия
  - Поддерживает второй круг при кольцевом маршруте
- **print_circleroute** - вывод кольцевого маршрута
  - Показывает связь последней остановки с первой

# Laba variant4.py:

Содержит функции для работы с отчетами и файлами:

- **stop** - добавление остановки в маршрут
- **totaltime** - расчет общего времени маршрута
- **save_report** - сохранение подробного отчета в текстовый файл
  - Сохраняет: количество остановок, общее время, список остановок
  - Формат: текстовый файл с таблицей
  - Пример: my_report.txt

- **save_base64** - сохранение маршрута в Base64 формате
  - Формат строки: название|x|y|время
  - Кодирует каждую остановку в Base64
  - Пример: my_route_base64.txt

- **load_base64** - загрузка маршрута из Base64 файла
  - Декодирует каждую строку
  - Восстанавливает список остановок
  - Возвращает: маршрут

- **printable** - вывод маршрута в виде таблицы с выравниванием колонок
